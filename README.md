# 🤖 Word3CounterBot

A powerful Telegram bot for real-time text analysis and word counting.

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/word3counterbot)

## 🌟 Features

- **📝 Word Counting** - Accurate word count for any text
- **🔤 Character Analysis** - Count with and without spaces
- **📄 Sentence Detection** - Automatic sentence counting
- **📑 Paragraph Analysis** - Detect paragraph structure
- **⏱️ Reading Time** - Estimate reading duration
- **🔑 Keyword Extraction** - Find important keywords
- **📊 Statistics** - Track your usage
- **⚡ Fast Response** - Real-time analysis

## 🚀 Quick Deploy

### On Railway

1. Click the "Deploy on Railway" button above
2. Add your `BOT_TOKEN` in environment variables
3. Deploy and go!

### Manual Setup

```bash
# Clone the repository
git clone https://github.com/yourusername/word3counterbot.git
cd word3counterbot

# Install dependencies
pip install -r requirements.txt

# Set environment variable
export BOT_TOKEN="your_bot_token_here"

# Run the bot
python app.py
